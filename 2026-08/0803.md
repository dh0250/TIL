# 리눅스 개요 (Linux 1)

운영체제의 정의와 구조(커널·인터페이스·시스템 호출·드라이버)를 먼저 짚고, 이를 바탕으로 리눅스가 무엇이고 왜 서버 운영체제로 널리 쓰이는지, 어떤 역사를 거쳐 어떤 배포판들로 갈라졌는지를 정리.

---

# 운영체제란?

컴퓨터 시스템의 자원들을 효율적으로 관리하며, 사용자가 컴퓨터를 편리하고 효과적으로 사용할 수 있도록 환경을 제공하는 여러 프로그램들의 모임. 하드웨어와 사용자 사이의 인터페이스로 동작하는 시스템 소프트웨어의 일종으로, 다른 응용 프로그램이 유용한 작업을 할 수 있도록 환경을 제공한다.

- **프로그램**: 하드디스크 같은 보조기억장치에 저장되어 아무 동작도 하지 않는 상태.
- **프로세스**: RAM 같은 메인 메모리에서 실행 중인 프로그램(program in execution).

---

# 운영체제의 구조: 커널과 인터페이스

운영체제는 크게 **커널**과 **인터페이스**로 나뉜다.

- **인터페이스**: 시스템 호출을 직접 다루지 않아도 간단한 명령이나 조작만으로 커널 기능을 이용할 수 있게 만든 소프트웨어. GUI(그래픽 기반)와 CLI(명령줄 기반)로 나뉜다.
- **시스템 호출**: 커널이 자신을 보호하기 위한 인터페이스. 시스템 관련 서비스를 함수 형태로 제공하면서, 사용자·응용 프로그램이 자원에 직접 접근하는 것을 차단한다.
- **커널**: 하드웨어와 소프트웨어 컴포넌트 사이의 핵심 인터페이스. 운영체제 최하위 수준에서 실행되며, 다른 모든 부분은 커널을 통해서만 하드웨어와 상호작용한다. 리눅스·윈도우·macOS는 각각 고유한 커널을 가지며, 이 커널이 운영체제의 특성과 성능을 결정한다.
  1. **리소스 관리**: CPU, 메모리, 디스크 공간 등을 관리.
  2. **프로세스 관리**: 프로세스 간 CPU 시간 분배, 생성과 종료 관리.
  3. **메모리 관리**: 메모리 할당·해제로 누수와 오버플로우 방지.
  4. **장치 드라이버와의 인터페이스**: 키보드·마우스·프린터·디스플레이 등 하드웨어 제어.
- **드라이버**: 커널과 하드웨어 사이의 인터페이스. 키보드·마우스처럼 단순한 장치의 드라이버는 커널에 내장되어 있지만, 프린터·그래픽카드처럼 크고 복잡한 장치는 사용자가 직접 설치해야 한다.

---

# 리눅스란?

오픈 소스 운영체제로, 컴퓨터 하드웨어·소프트웨어 리소스 관리와 사용자-프로그램 간 인터페이스를 제공한다. 안정성·보안성·유연성이 뛰어나 웹서버, 애플리케이션 서버, 데이터베이스 서버 등 다양한 용도로 쓰인다.

리눅스를 서버로 많이 쓰는 이유:

1. **무료 오픈 소스**: 대부분의 배포판이 무료이며, 필요에 따라 소스 코드를 수정·배포할 수 있다.
2. **안정성 및 신뢰성**: 재부팅 없이 오랜 시간 실행될 수 있어 서버 운영에 중요하다.
3. **보안**: 기본적으로 보안이 강화된 설계이며, 정기 업데이트와 커뮤니티 지원으로 높은 보안성이 유지된다.
4. **성능**: 자원을 효율적으로 사용해 시스템 성능을 최적화한다.
5. **다양한 배포판**: 서버 용도에 맞는 배포판(Ubuntu, CentOS, Debian 등)을 선택할 수 있다.

---

# 리눅스의 역사

1991년 핀란드 헬싱키 대학교 학생이던 리누스 토발즈(Linus Torvalds)가 처음 개발. 원래는 MINIX(작은 유닉스 시스템)를 쓰다가 제한이 많아 실망한 끝에 자신만의 운영체제를 만들기로 결심한 것으로 알려져 있다. 공개 이후 수많은 개발자가 참여하면서 안정성과 효율성을 갖춘 리눅스 커널로 발전했고, 지금도 전 세계 개발자들이 무료 오픈소스로 수정·기능 추가를 이어가고 있다. 유닉스 클론이었던 리눅스는 커널을 기반으로 다양한 배포판을 낳았고, 서버·데스크톱·모바일·임베디드 시스템 등 다양한 분야에서 쓰이고 있다.

- **GNU 프로젝트**: 컴퓨터 프로그램의 저작권을 없애 모두가 공유할 수 있는 소프트웨어를 만들고, 복제·변경·소스 코드 제한을 철폐하는 데 가치를 둔다. 자유 소프트웨어 재단(FSF)의 리처드 스톨만이 주축이 되어 설립했으며, GPL 라이선스로 자유 소프트웨어 개념을 도입했다.
- **자유 소프트웨어**: 소스 코드의 공개·사용·수정·재배포의 자유, 수정한 소프트웨어를 판매할 자유를 뜻한다.

# 리눅스의 종류

특정 목적·사용자·기능에 맞춰 다양한 배포판으로 제공된다.

| 계열 | 종류 | 설명 |
| --- | --- | --- |
| Debian 계열 | Ubuntu | 가장 인기 있는 데스크탑 배포판 중 하나로, 사용자 친화적이며 초보자에게 적합하다. |
| Debian 계열 | Debian | 안정성과 보안에 중점을 둔 배포판으로, 다양한 아키텍처를 지원한다. |
| Debian 계열 | Mint | Ubuntu 기반으로 향상된 사용자 경험을 제공하며, 초보자에게 적합하다. |
| Redhat 계열 | Fedora | 최신 기술을 빠르게 채택해 개발자와 고급 사용자에게 인기가 있다. |
| Redhat 계열 | CentOS | 엔터프라이즈 수준의 안정성을 제공하는 서버용 배포판으로, RHEL의 무료 대체제로 호환된다. |
| Slackware 계열 | openSUSE | 안정적이고 다기능적인 배포판으로, 서버와 데스크톱 양쪽에서 사용된다. |

---

# 전체 흐름 정리

1. 운영체제는 하드웨어와 사용자를 잇는 시스템 소프트웨어이며, 크게 **커널**(리소스·프로세스·메모리 관리, 장치 드라이버 인터페이스)과 **인터페이스**(GUI/CLI, 시스템 호출을 통한 커널 접근)로 구성된다.
2. 리눅스는 이 구조를 갖춘 오픈 소스 운영체제로, 무료·안정성·보안·성능·다양한 배포판이라는 이유로 서버 환경에서 특히 많이 쓰인다.
3. 1991년 리누스 토발즈가 MINIX의 한계에 실망해 직접 만든 것이 리눅스 커널의 시작이며, GNU 프로젝트의 자유 소프트웨어 철학과 결합해 지금의 오픈소스 생태계로 이어졌다.
4. 같은 리눅스 커널 위에서 Debian(Ubuntu, Debian, Mint), Redhat(Fedora, CentOS), Slackware(openSUSE) 계열 등 목적에 따라 다른 배포판이 갈라져 나왔다.
